Instalación
===========

Requisitos
----------

Para utilizar Ize es necesario disponer de:

* Blender
* Ize Logger
* Ize Insights

Instalación de Ize Logger
-------------------------

1. Abre Blender.
2. Accede a ``Edit > Preferences``.
3. Abre la sección de complementos.
4. Selecciona la opción para instalar un complemento desde disco.
5. Selecciona el archivo ZIP de Ize Logger.
6. Activa el complemento.

Después de instalarlo, el panel de Ize Logger aparecerá en la
interfaz de Blender.

Instalación de Ize Insights
---------------------------

1. Abre Blender.
2. Accede a las preferencias.
3. Instala el archivo ZIP de Ize Insights.
4. Activa el complemento.

.. note::

   Ize Insights puede requerir dependencias adicionales para
   realizar determinadas operaciones de análisis y visualización.
