Solución de problemas
=====================

El complemento no aparece
--------------------------

Comprueba que el complemento está correctamente instalado
y activado en Blender.

Ize Insights no puede cargar los datos
--------------------------------------

Comprueba que el archivo seleccionado corresponde a un
registro válido generado por Ize Logger.

Problemas con dependencias
--------------------------

Si una biblioteca necesaria no está disponible, comprueba
la instalación de las dependencias de Ize Insights.
