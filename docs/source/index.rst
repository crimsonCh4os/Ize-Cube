Ize documention
===============

Documentación oficial de los complementos Ize para Blender.

Ize permite registrar interacciones realizadas durante el uso de
Blender y posteriormente analizar los datos obtenidos.

La solución está formada principalmente por:

* **Ize Logger**, encargado de registrar la interacción.
* **Ize Insights**, encargado de analizar y visualizar los datos.
